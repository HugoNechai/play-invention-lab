# Play Invention Lab

A collection of hands-on experiments in creative coding, computer vision,
interactive play and physical-digital prototyping.

The goal of this repository is to explore how physical actions, objects and
environments can interact with software and create playful digital responses.

## Experiments

### 01 — Wave to Wake
**Tools:** Python, OpenCV, webcam

Move a physical object in front of the camera and wake up a digital character.

**Interaction:**
Physical movement → Camera → Motion detection → Digital response

_Status: In progress_
